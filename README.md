# VEX Over Under

Robot code for the VEX V5 Over Under season. C++.

## What's inside

- **Puncher** (`src/puncher.cpp`): catapult-style launcher control with a slip-gear model. Spin one revolution, spin to an angle, and count punches.
- **Wings** (`src/wing.cpp`).
- **PID control** (`src/utility/pid_control.cpp`) and button helpers (`src/utility/buttons.cpp`).
- **Autonomous routines** (`src/auton.cpp`, `src/auton_functions.cpp`).
- **Driver control** in `src/botcontrol.cpp` and `src/basic_controls.cpp`.

## Build

A makefile-based VEX V5 project. Open it in VS Code with the VEX extension, build, and download to the Brain.
